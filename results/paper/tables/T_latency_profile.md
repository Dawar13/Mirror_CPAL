## M2 profile: where the time goes (runs/m2_profile/m2_profile.csv, m2_submodules.csv)

Kernel time per forward by category, ms and share of the kernel time (scripts/m2_profile.py sorts every GPU activity into a category by its name; time_source says whether these are CUDA kernel times or, in the CPU smoke test, operator self times). Idle = median latency minus kernel time. Gap = median latency minus the dense model's (same model, mode and batch; dense is the folded original in the same implementation). The category changes plus the idle change add up to the gap (gap_check in the CSV). Sub-modules: each converted block's MLP, attention and stream rotations timed alone against the same block of dense, summed over the timed blocks (sub_blocks, 0-based block indices as in m2_submodules.csv); remainder = gap minus the summed sub-module changes (norms, residual adds, launch overheads).
